Pocket Vet

Pocket Vet is a collection of veterinary reference tools for canine and feline care. It includes separate applications for anesthesia.

Status: Clinical prototypes. Veterinary review and validation are required before patient-care use.

Applications

Pocket Vet Anesthesia

Emergency drug calculations and external/internal defibrillation energy calculations.

Anesthetic drug calculators with editable concentrations.

Fentanyl, FLK, Ketamine, and Propofol CRI calculators.

Fluid rates, boluses, and drip calculations.

Respiratory calculations, including oxygen flow, tidal volume, and reservoir bag sizing.

Preanesthetic and post-operative recovery checklists.

Anesthetic monitoring records with parameter trend graphs.

Printable worksheets and downloadable records.
